## Запуск у рэжыме эмуляцыі (эмулятар "на стале")

Усе необходныя кампаненты (такія як: EasyServer, Monitor) знаходзяцца [тут](https://github.com/savushkin-r-d/SCADA-ptusa-bin).

Шляхі да необходных файлаў будуць залежыць ад таго, на яком локальным дыске вашага камп'ютара вы іх размясцілі.

У гэтай інструкцыі ўсе файлы знаходзяцца на дыску D:\.

### Кланіраванне праекта

Праект T1_PLCNext_Demo знаходзіцца [тут](https://github.com/savushkin-r-d/T1-PLCnext-Demo).

Каб кланіраваць рэпазіторый, выканайце наступную каманду:

```cmd
git clone --recurse-submodules https://github.com/savushkin-r-d/T1-PLCnext-Demo.git
```

### Устаноўка Visual Studio Code

Апошняя версія Visual Studio Code знаходзіцца [тут](https://code.visualstudio.com/download).

Каб устанавіць Visual Studio Code, выканайце наступныя дзеянні:

- Скачайце файл прашыўцы фармату *.exe апошняй версіі з сайта.

- Запусціце файл ўстаноўкі *.exe.

- Прытрымлівайцеся ўказанняў майстра ўстаноўкі.

### Устаноўка Git LFS

Апошняя версія Git LFS знаходзіцца [тут](https://git-lfs.github.com/).

Каб устанавіць Git LFS, выканайце наступнае:

### Устаноўка файлаў прашыўкі

Апошняя версія прашыўкі знаходзіцца [тут](https://www.phoenixcontact.com/en-pc/products/controller-axc-f-2152-2404267#downloads-link-target), у раздзеле Firmware спампуйце апошнія версіі Hardware Version і Compatible Tools.

Каб абнавіць прашыўку кантролера, выканайце наступныя дзеянні:

- Скачайце файл прашыўкі фармата *.zip апошняй версіі **LTS** на сайце Phoenix Contact.

- Распакуйце *.zip файл прашыўкі.

- Запусціце файл устаноўкі *.exe.

- Прытрымлівайцеся парадам майстра ўстаноўкі.

Пры ўстаноўцы, файл прашыўкі (*.raucb) і PDF-файлы з інфармацыей аб прыладзе будзуць скапіраваны ў выбраны каталог.

#### Абнаўленне прашыўкі праз вэб-браузэр

Для абнаўлення прашыўкі кантролера неабходно ў галіне **Administration** перайсці ў укладку **Firmware update**.

<p align="center">
<img align="center" src="images/firmware_page.PNG" height="400">
</p>
<p align="center"> Рысунак 23 - Старонка абнаўлення прашыўкі </p>

Затым націснем на кнопку **Browse...**, выбіраем файл прашыўкі (*.raucb) і ціснем на *Ok*.

Прашыўка будзе абноўлена. Калі пры абнауленні прашыўкі святлодыёд RUN пачынае мігаць, а затым гасне.
Пасля гэтага кантролер перазапускаеца. Пасля поўнай ініцыялізацыі кантролёра светлодыёд RUN гарыць заўсёды.

#### Абнаўленне прашыўкі кантролера праз камандную абалонку

- Адкройце кліентскае праграммнае забеспячэнне SFTP (напрыклад, [WinSCP](https://winscp.net/eng/index.php)).

- Аўтарызуйцеся як адміністратар.
<p align="center">
<img align="center" src="images/winscp.png">
</p>
<p align="center"> Рысунак 24 - Аўтарызацыя ў WinSCP </p>

Па змаўчанні ўведзіце наступныя дадзеныя для аўтарызацыі:

```bash
Імя карыстальніка: admin
Пароль: на кантролеры.
```

<p align="center">
<img align="center" src="images/password_placement.png" height="400">
</p>
<p align="center"> Рысунак 25 - месцазнаходжанне пароля </p>

- Скапируйце файл прашыўкі *.raucb у **/opt/plcnext** каталог (каталог па змаўчанні карыстальніка Linux «admin»).

- Адкройце камандную абалонку з дапамогай інструмента каманднага радка (напрыклад, [PuTTY](https://www.putty.org/), у WinSCP спалучэнне клавіш Ctrl+P).

- Аўтарызуйцеся як адміністратар.

Па змаўчанні уведзіце наступныя дадзеныя для аўтарызацыі:
Імя карыстальніка: admin
Пароль: на кантролеры.

- Перайдзіце у **/opt/plcnext** каталог (каманда: *cd /opt/plcnext*).

- Для абнаўлення прашыўкі ўведзіце каманду:

```sh
sudo update-axcf2152
```

Патрэбна ўвесці пароль адміністратара.

Прашыўка будзе абнаўлена. Пры абнаўленні прашыўкі светлодыёд RUN пачне мігаць, а затым гасне.
Пасля таго кантролер перазапускаецца. Пасля поўнай ініцыялізацыі кантролера светлодыёд RUN гарыць заўсёды.

### Капіраванне Lua-файлаў праекта

Патрэбна праз **SFTP** інтэрфэйс запісаць файлы канфигурацыі праекта на кантролер у каталог **/opt/main**.

Для гэтага прапануецца выкарыстоўваць праграму [WinSCP](https://winscp.net/eng/index.php).

Выбіраем файлы праекта, якія необходна записаць на кантролер. Гэтыя файлы знаходзяцца ў каталоге праекта. Спис файлаў, якія апісваюць праект:

- __*main.plua*__ - апісанне кіруючай праграмы;
- __*main.io.lua*__ - апісанне прывязкі прылад да модулей увода/вываду;
- __*main.modbus_srv.lua*__ - апісанне ўзаемадзеяння з modbus-кліентамі;
- __*main.objects.lua*__ - апісанне аб'ектаў праекта;
- __*main.profibus.lua*__ - апісанне profibus;
- __*main.restrictions.lua*__ - апісанне абмежаванняў;
- __*prg.lua*__ - апісанне прылад, агрэгатаў.

Таксама неабходна скапираваць сістэмныя файлы з каталога **sys**. Спис сістэмных файлаў:

- __*sys.devices.lua*__ - апісанне прылад;
- __*sys.objects.lua*__ - апісанне аб'ектаў;
- __*sys.io.lua*__ - апісанне модулёў увода-вываду;

Капіруем дадзеные файлы на кантролер у асобна створаны каталог **/opt/main/sys**.

### Актывацыя ўваходу па SSH у якасці карыстальніка root

- Далучыцеся да кантролера і ўвайдзіце ў сістэму **admin**.

- Адчыніце файл */etc/ssh/sshd_config* у прыдатным рэдактары ў **WinSCP**.

- У раздзеле #Authentication: раскаментуйце запісь: `#PermitRootLogin yes`.

- Перазапусціце службу SSH з дапамогай *sudo /etc/init.d/sshd restart*

### Деактывацыя ўвхода па SSH у якасці карыстальніка root

- Далучыцеся да кантролеру і ўвайдзіце ў сістэму **admin**.

- Адчыніце файл */etc/ssh/sshd_config* у прыдатным рэдактары (**WinSCP**).

- У раздзеле #Authentication: закаменціруейце запісь: `PermitRootLogin yes`.

- Перазапусціце службу SSH з дапамогай *sudo /etc/init.d/sshd restart*

### Запуск праекта праз кансоль

Для запуска праекта праз кансоль патрэбна:

1. Устанавіць Toolchain патрэбнай версіі (подрабязная інструкцыя па ўстаноўцы [тут](https://github.com/savushkin-r-d/ptusa_main#using-plcnext-technology-c-toolchain-in-windows)).

2. Далучаемся да кантролера праз карыстаўніцкае праграмнае забеспячэнне [WinSCP](https://winscp.net/eng/index.php).

3. Перайсці ў каталог для свайго кантролера `ptusa_main\bin\install\AXCF3152\Release\bin\` і адсюль скапіраваць выканальны файл `ptusa_main` у свой каталог на кантролеры, напрыклад, `/opt/main/`.

4. Далей ў гэты самы каталог скапіраваць файлы з пашырэннем `lua` і `plua`, а таксама дырэкторыі `spec` і `sys` з праекта `T1-PLCnext-Demo`.

5. Пасля чаго адчыніць Kitty, перайсці ў каталог з ўсімі скапіраванымі файламі

```bash
cd /opt/main/
```

І запусціць выкананы файл `ptusa_main`

```bash
./ptusa_main main.plua sys_path ./sys/
```

Калі ўзнікаюць памылкі `Permission denied`, дабаўце файлу флаг -x, каб зрабіць яго выконвываючым. Гэта можна зрабіць альбо праз інтэрфэйс ***WinSCP***, альбо праз кансоль з дапамогай каманды `chmod`.

```bash
chmod +x ptusa_main
```
